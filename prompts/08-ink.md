# Boiling Ink

Draw an ink sketch on cream paper #f4ecd8 with fibre grain and a warm vignette,. Every contour is a ribbon rebuilt each frame: resample the path every 5 px, push it sideways with smooth noise of about 1.5 px, and taper the width from 5 px to 1.5 px. Split long outlines into 150 px strokes that overshoot corners. Change the noise seed only every 1/8 s, floor(t * 8), so lines boil on threes while the rig moves smoothly. Ink is #16120d. Under it, lay multiply washes offset about 3 px from each shape: faded vermilion #d9432a (hoodie, pot), ochre #dca233 (lamp, moon), grey-blue #6d89a1 (night window, jeans). Shade with hatching: parallel strokes that start on the edge away from the top-left light and run inward, with a crossing set in the darkest spots (under the desk, sill, feet). Add grey pencil circles on the joints, a floor timing chart, and "take 7" lettered in the margin. At 2.8 scribble the screen solid dark green, letter SHIPPED in paper colour with a double underline, burst thick ink rays from the laptop, throw scribbled stars, loops and zigzags, and draw a pencil tick by the note.
